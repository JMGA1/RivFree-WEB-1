 RivFree — Comparador de Preços de Free Shops

Projeto desenvolvido para a disciplina de Programação Web 1. O objetivo é criar um comparador de preços dos free shops da fronteira entre Rivera e Santana do Livramento reunindo ofertas, informações das lojas e uma lista de compras em um só lugar.

Nesta primeira etapa, o projeto conta apenas com a estrutura base (esqueleto) em HTML5 semântico:

* Etapa 1`index.html` — Página inicial, busca, destaques e catálogo. 
* Etapa 2`lojas.html` — Guia com os free shops da fronteira.
* Etapa 3`lista.html` — Minha lista de produtos salvos.
* Etapa 4`sobre.html` — Informações sobre o projeto e privacidade.
* Etapa 5`contato.html` — Formulário de contato e sugestões.
